[Project 1 : Household Income Prediction: A Machine Learning Analysis](https://www.kaggle.com/code/bouthainabouaziz/us-household-income-prediction)

**Built a predictive model achieving 99.92% accuracy to estimate mean household income across 32,000+ US locations, demonstrating end-to-end machine learning expertise with real-world business applications.**

### 🎯 Data & Problem Framing
- Processed 32,000+ location records with comprehensive geographic and household statistics
- Engineered 11 new features (Population Density, Income Inequality, Wealth Index, Distance From Center, and log transformations)
- Validated data quality: zero missing values, zero infinite values

### 🔧 Solution Architecture
- End-to-end pipeline: Data Import → EDA → Feature Engineering → Feature Selection → Model Training → Evaluation
- Selected 19 optimal features from initial dataset
- Implemented three ensemble algorithms for comparative analysis

### 🎓 What I Learned
- ✅ High-dimensional feature engineering and selection strategies
- ✅ Trade-offs between model complexity and interpretability
- ✅ Strategic outlier retention vs. removal decisions
- ✅ Ensemble model comparison and hyperparameter optimization
- ✅ Cross-validation for robust performance estimation


[Project 2 # Bank Credit Default Prediction 🏦](https://www.kaggle.com/code/bouthainabouaziz/loan-default-prediction)

**Predictive ML model to identify loan defaults with full interpretability & regulatory compliance.**

### 🎯 Problem Statement
Banks need to accurately predict loan defaults to:
- Minimize financial losses
- Allocate capital efficiently
- Comply with Basel III & IFRS 9 regulations
- Provide transparent credit decisions

### 📊 Dataset
- **Size**: ~12K+ loan records from 12 parquet files
- **Target**: Binary classification (Default/Non-Default, ~X% default rate)
- **Features**: 60+ including payment history, utilization ratios, delinquency patterns

### 🔧 Solution Architecture

Data Loading → EDA (8 phases) → Feature Engineering → Modeling → Interpretability


### 🎓 What I Learned
- ✅ End-to-end ML pipeline from raw data to production
- ✅ Model interpretability (SHAP) for stakeholder communication
- ✅ Regulatory compliance (Basel III, IFRS 9)
- ✅ Handling imbalanced classification
- ✅ Causal inference vs correlation
- ✅ SQL for production deployment
